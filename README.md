# Onfile
Find filenames across your drives. Then open the file, the folder, or a terminal.

Onfile is a Windows tray app for finding files on local drives and network shares.

**Status:** 1.1.0 Public Preview — free to use. A paid license may apply to later major versions.

## Download

[Onfile 1.1.0 Setup](https://github.com/esimplesoftware/onfile/releases/latest)

Windows 10/11 64-bit. SmartScreen may warn until the app has an Authenticode certificate. More info → Run anyway.

## Search filters

- `list D:` — one volume
- `list*` — name starts with list
- `*.txt` — extension
- `"exact name.txt"` — exact name
