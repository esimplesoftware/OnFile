Privacy and encryption

The file index is encrypted for this Windows user on this PC. There is no password to set. Onfile does not send file names, paths, or searches anywhere. Full details: Onfile privacy statement.

What is encrypted

  • onfile.db — file and folder names, paths, and volume scan state.
  • onfile.db.key — the sealed key. Onfile creates it beside the index.

Settings in onfile.ini and the log are not encrypted. Onfile does not send the index anywhere.

If support asks you to start Onfile with --verbose, extra detail is written to onfile.log.verbose. File names, folder paths, and search text are replaced with a length and a short code unless you also add --verbose-names. The verbose file is deleted the next time Onfile starts normally.

What this means

  • A copy of the database on another PC, or opened by another Windows user, cannot be read.
  • A database browser cannot open it.
  • Deleting onfile.db.key makes the index unreadable. There is no recovery key.
  • Backup both files together, and only restore them for the same Windows user on the same PC. Exit Onfile before you copy them.

Older plain index

The renamed file is not used. Onfile deletes it automatically once all your volumes have finished scanning into the new encrypted index.

If open fails, see Troubleshooting.

Settings and logs

  • onfile.ini lists the drives and shares you added, your include and exclude filters, schedules, and window position. It does not store searches.
  • onfile.log records the drives and shares Onfile scans, record counts, and errors. It does not record file names or searches.
  • The helper service writes usn-helper.log in %LOCALAPPDATA%\Onfile. It records drive letters, service start and stop, and errors. It does not record file names.

Clipboard and memory

  • Copy path and Copy name put text on the Windows clipboard. If Windows clipboard history or cloud clipboard is turned on, Windows may keep that text.
  • While Onfile is open, the names it shows are in its memory, as in any program. Other programs need your account or administrator rights to read it.

Network

Onfile does not send your computer name, file names, paths, or searches.

Online help. With Help > Use Online Help on (the default), opening help checks onfile.esimplesoftware.com for the current page for your version and opens it in your browser. Only the page address is sent. If the site cannot be reached, the installed help opens instead. Turn the option off to keep help fully offline.
