How it works

You control the index. Onfile does not pretend every location behaves like C:.

01

You pick the locations

Add NTFS, FAT32 and exFAT drives, plus network shares. Nothing else is in the index.

02

Local NTFS stays fresh. Shares follow your schedule.

Local NTFS follows the change journal. Shares and other drives are scanned when you ask, or on a schedule you set per volume.

03

The result is the action

Find the file, then open it, open the folder, copy the path or name, or open your default terminal in that folder.

What it does and does not do

Name and path search on locations you add. That is the whole product.

Does

  • Index filenames and paths on drives and shares you add
  • Keep local NTFS current from the change journal
  • Scan shares and other drives when you ask, or on a schedule
  • Search inside one folder of the index
  • Open file, folder, copy path or name, open a terminal in that folder
  • Encrypt the index database on disk

Does not

  • Search inside file contents
  • Pretend a network share scan is as instant as local NTFS
  • Index locations you never added, or removable disks
  • Upload your file list (search stays on your PC)

Questions

Short answers. The limits are intentional.

Is this Everything?

Everything is excellent for local NTFS names. Onfile is built around locations you add, including shares you scan on demand or on a schedule, and actions on the result.

Will my network shares be instant?

After a scan, you search the index instantly. The scan itself depends on the share. You start it, or set a schedule; Onfile must be running for a scheduled scan to start.

Does it search inside PDFs or documents?

No. Names and paths only.

Which terminal does it open?

The one you choose under Tools → Default terminal. It opens in the folder that contains the selected file.

Is it free?

Yes. Onfile is free. It needs a license key starting with ONFILE-. Activate it under Help → License. One key works on two PCs, and Onfile keeps working offline for 30 days between checks.

Does it send my files anywhere? Only the license check talks to the license server. Read the privacy statement.
