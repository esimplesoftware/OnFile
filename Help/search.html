Search

Onfile matches names and paths, not file contents. Only enabled (not paused) volumes are searched.

How to search

  • Type in the box at the top. Search runs after a short pause.
  • Search starts at 2 characters.
  • If the query has a run of 3 or more plain characters (for example list in list*.txt), Onfile uses the saved search index and results are almost instant.
  • If it does not (for example li, *.c, l?st), Onfile checks every saved name instead. These searches still work but can take several seconds on large volumes.
  • The search index is built once after a fresh scan and kept up to date afterwards. While it is building (status bar shows done / total), searches may be slower or incomplete.
  • The first search after startup can take a few seconds. Later searches are faster.
  • Results are ranked: exact name first, then prefix, then substring, then path.
  • The list shows up to 200 matches. Narrow the query if you do not see the file.

Wildcards

  • * matches any run of characters (including none). ? matches exactly one character. Both work anywhere in the pattern.
  • A pattern with wildcards must match the whole file name. list*.t does not find list.txt; use list*.t*.
  • Matching ignores case. Folder names in the path are not matched, only the file’s own name.
  • Inside quotes, * and ? are ordinary characters.

A trailing d: or \\server limits which volume is searched. There is no AND/OR and no regular expressions.

Searching inside a folder

Put a folder path after the name: list c:\, list c:\program files\, *.txt d:\projects\. Only files under that folder are returned. Folder names with spaces are fine.

  • When there are more matches than fit in the list (200), a folder list opens next to the results. It shows the subfolders one level down and how many matches each one holds (Folder / File Count), largest first.
  • Click a folder to add it to the search box and drill down. Repeat until the results fit.
  • (here) counts matches directly in the current folder, not in a subfolder.
  • End the path with \ to mean “this folder”. Without it, the last part is treated as the start of a folder name: list c:\prog matches Program Files, ProgramData, … Backspacing to edit the path works the same way.
  • The folder list hides when all matches fit or there are no subfolders to drill into.

Results

The list shows name and path. Selecting a row shows modified time, size, and created time when the file is still on disk.

  • Enter — open the file or folder.
  • Ctrl+Enter — open the containing folder.
    • open your default terminal there (choose it under Tools → Default terminal).
  • Ctrl+C — copy the path. Ctrl+Shift+C — copy the name.

The result count and time are on the status bar. If a second drive seems missing from results, narrow the query (add e:) or see Troubleshooting.
