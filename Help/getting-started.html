Onfile Help · Getting started

Getting started

Add a drive, wait for the index, then type in the search box.

First run

  1. Start onfile-ui.exe.
  2. Add a volume: a fixed local drive or a network share (\\server\share).
  3. Let Onfile scan (or choose Scan now). Wait until the volume shows Synced.
  4. Type at least two characters in the search box. Three or more characters search the saved disk index.

The window opens before loading finishes. The first search after startup can take a few seconds. Later searches are faster. A search-index rebuild runs in the background.

The window

  • Search box — name search over enabled volumes.
  • Results — matching files and folders. Selecting a row shows modified time, size, and created time when the file is still on disk.
  • Volume list — each drive or share, its state, and a status icon. See Volumes.
  • Status bar — volume status, live update, search result count and time, and search-index progress (done / total).

Closing the window hides Onfile in the notification area. To quit, use Exit on the tray menu or in the app menu.

Tray and hotkey

  • Left-click the tray icon to show the window.
  • Right-click for Show or Exit.
  • The hotkey is Ctrl+Shift+F.

If the hotkey does nothing, see Troubleshooting.

Where files are stored

Onfile keeps its own settings, index, and log. You do not need to edit those files.

  • %APPDATA%\Onfile\onfile.ini — settings Onfile writes
  • %APPDATA%\Onfile\onfile.db — index, encrypted for this Windows user
  • %APPDATA%\Onfile\onfile.db.key — sealed key. Leave this next to the index.
  • %APPDATA%\Onfile\onfile.log — log

If a settings file is already next to the program, Onfile uses that folder instead.

The index cannot be opened on another PC or by another Windows user. See Index encryption.
