Onfile Help · Live update

Live update

On local NTFS drives, Onfile can follow Windows’ change journal so new, renamed, and deleted files appear without a full rescan.

Status line

  • Live update on — the helper service is running and Onfile can talk to it.
  • Live update off — helper not installed or not running. Search still uses the last index. Use Scan now when files change.

Network shares never use live update. Scan those when the tree changes, or use Schedule.

The helper

A small service named Onfile USN Helper reads the journal so Onfile itself does not need to stay elevated.

  • onfile-usn.exe must sit next to onfile-ui.exe.
  • After the index loads, Onfile may ask Windows for permission to install the helper. Choose Yes.
  • The installed copy lives in %LOCALAPPDATA%\Onfile.

You can refuse the prompt. Search and manual scan still work.

When to scan anyway

  • Volume state is Stale or Error.
  • You changed include/exclude filters (old files are not stripped until a scan).
  • Live update is off and you know the disk changed.
